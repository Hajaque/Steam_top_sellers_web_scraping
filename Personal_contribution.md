# Tasks Completed

I conducted web scraping of Steam Top Sellers data for seven consecutive days, from 13 to 19 October 2026. I collected game information and saved the results in daily CSV files. After data collection, I merged the seven datasets into one dataset and performed data cleaning. This involved checking missing values, identifying duplicate records, and preparing the data for analysis. I then loaded the cleaned dataset into MySQL for structured storage and querying.
